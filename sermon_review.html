🎤 이번 주 설교 자료

설교 요약 · 복습 · 5일 묵상을 한글/영어로 바로 확인해요. 기본으로는 매일 빌드 시점에 구워넣은 이번 주 자료(정적 스냅샷)를 바로 보여줘서 아이패드를 포함한 모든 기기에서 동작하고, 자료는 토요일마다 다음 주 것으로 바뀌기 전까지는 그대로예요. Chrome/Edge 데스크톱에서는 🔄 실시간 볼트 연결로 옵시디언 볼트를 직접 읽어 최신 파일을 강제로 확인할 수도 있어요.

정적 스냅샷 준비 중…
실시간 볼트 연결은 Chrome / Edge 데스크톱에서만 동작해요 (File System Access API — Safari/Firefox 미지원, iPad/iPhone 사용 불가). 아래 자료는 정적 스냅샷이라 이 브라우저에서도 계속 볼 수 있어요.
폴더를 연결하면 이번 주 설교 자료가 여기 표시돼요.
